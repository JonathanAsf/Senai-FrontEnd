# 🧩 Exercício - CSS Grid

Este projeto foi desenvolvido durante o curso de **Front-End no SENAI Suíço-Brasileiro**.  
O objetivo é praticar os conceitos de **CSS Grid Layout**, explorando **divisões de colunas e tamanhos**.
